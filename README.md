# ARIA 🤖

Personal AI assistant project built step by step with Python, Ollama and AI/ML.

## Goal
Build a private personal assistant that:
- communicates in Persian
- uses a local LLM when possible
- keeps structured memory with owner control
- asks for approval before sensitive actions
- learns through documented, testable steps
- runs code and tools inside safe boundaries

## Learning path
1. Python
2. Ollama and local LLMs
3. LLM APIs
4. Memory
5. Tool calling
6. RAG
7. AI agents
8. Machine Learning

This repository documents the real learning and development process.
