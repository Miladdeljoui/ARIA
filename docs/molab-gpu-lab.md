# آزمایشگاه GPU مولاب برای ARIA

این بخش، یک محیط آزمایش شخصی برای اجرای تعاملی مدل‌های متن‌باز در [Molab](https://molab.marimo.io/) است.

## راه‌اندازی

1. فایل [aria_molab_gpu_lab.py](../notebooks/aria_molab_gpu_lab.py) را در مخزن باز کن.
2. در Molab وارد حساب شو و از قابلیت Mirror/Import from GitHub، مخزن Miladdeljoui/ARIA و فایل Notebook را انتخاب کن.
3. از منوی مشخصات Notebook، GPU را فعال کن و Save and restart را بزن.
4. وضعیت GPU و VRAM را در ابتدای Notebook ببین.
5. مدل Qwen3-4B یا Qwen3-8B را انتخاب و بارگذاری کن. دانلود مدل در اولین اجرا زمان و اینترنت می‌خواهد.

## محدودیت مهم

Molab یک محیط Notebook تعاملی است، نه VPS دائمی یا API عمومی برای اپ اندروید. طبق [مقررات استفاده از Molab](https://marimo.io/pages/molab/restrictions)، بیرون‌دادن GPU به ترافیک خارجی، ساخت پراکسی، میزبانی وب‌سرویس، بازنشر endpointهای هوش مصنوعی یا فروش مجدد محاسبات مجاز نیست. بنابراین این Notebook به ARIA APK متصل نمی‌شود و عمداً هیچ تونل یا API عمومی ایجاد نمی‌کند.

مستندات فعلی Molab می‌گویند هر Notebook به‌طور پیش‌فرض ۴ CPU و ۳۲ گیگابایت RAM دارد؛ GPU قابل انتخاب RTX PRO 6000 Blackwell با ۹۶ گیگابایت VRAM است. نشست‌ها حداکثر ۱۲ ساعت و پس از ۹۰ دقیقه بی‌کاری متوقف می‌شوند. دسترسی ممکن است با توجه به ظرفیت سرویس تغییر کند.

**محدودیت جغرافیایی:** صفحهٔ مقررات رسمی Molab ایران را در فهرست مناطق غیرمجاز برای حساب‌هایی که از آنجا منشأ می‌گیرند قرار داده است. نباید برای دورزدن این محدودیت از پراکسی یا VPN استفاده کرد.

## اتصال واقعی ARIA به چت ابری

چت عمومی ARIA باید از یک API مجاز و پایدار استفاده کند، نه از نشست Molab. برای آزمایش بدون هزینهٔ مدل متنی، پروژه از OpenRouter با مدل‌گردان openrouter/free پشتیبانی می‌کند. کلید API باید فقط در Secretهای سرور با نام ARIA_API_KEY ثبت شود؛ هرگز آن را داخل APK یا GitHub قرار نده.

سرویس رایگان OpenRouter سهمیه و محدودیت درخواست دارد و برای سرویس عمومی نامحدود تضمین‌شده نیست. ساخت تصویر و ویدئو مسیرهای جدا دارند و تا زمانی که سرویس‌دهنده و اعتبارشان روی سرور تنظیم نشده باشد، فعال نمی‌شوند.
