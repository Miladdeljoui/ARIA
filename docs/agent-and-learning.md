# خودآموزی + کنترل امن لپ‌تاپ + اندروید + تحریم

## ۱) خودش یاد بگیرد (روزانه)

در چت بگو:

- `صف یادگیری: پایتون, اندروید, فیزیک کوانتوم`
- `خودآموزی روشن`
- `خودآموزی خاموش`
- `الان یاد بگیر`

ARIA موضوعات را در `aria_learn_queue.json` نگه می‌دارد و با دستور یا زمان‌بندی در `lessons` ذخیره می‌کند.

## ۲) کنترل لپ‌تاپ

**اصل ایمنی:** پیشنهاد → تأیید مالک → اجرا.

مجاز با تأیید:
- نوشتن فایل داخل ریپوی ARIA / `generated/`
- چند دستور سفید (git status, ollama list, …)

غیرمجاز:
- حذف سیستم، فرمت، نصب پنهان، دسترسی خارج از پروژه

## ۳) «برو Android Studio و بساز»

واقعیت مهندسی:
- ARIA می‌تواند **طرح بسازد** و **اسکلت کد Compose** در `generated/android/` بنویسد.
- باز کردن Android Studio و Build نهایی را **تو** انجام می‌دهی (یا با تأیید صریح در نسخه‌های بعدی automation محدود).

دستور نمونه:
- `برنامه ساخت اپ: دفترچه یادداشت فارسی`
- `اسکلت اندروید: صفحه تنظیمات` (بعد تأیید نوشتن)

## ۴) تحریم و GitHub

- `جستجو گیت‌هاب: jetpack compose navigation`
- `ریپو گیت‌هاب: offline first android`
- `راهنمای میرور ایران`

ARIA لینک و نام ریپو می‌دهد تا clone کنی وقتی CDN رسمی قطع است.

## ۵) مسیر نجات آینده

یادگیری گسترده + ساخت ابزار توسط خودت با کمک ARIA = مسیر درست.  
کنترل بی‌اجازه کل ویندوز = مسیر فیلم تعالی که عمداً پیاده نمی‌شود.
