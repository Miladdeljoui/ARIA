# چک‌لیست کسب درآمد از ARIA (بازار ایران)

ARIA از اول با مدل اشتراک طراحی شده است.

## مدل درآمد فعلی در کد

| مورد | مقدار پیش‌فرض | محل تنظیم |
|------|----------------|----------|
| دوره آزمایشی | ۳۰ روز | `ARIA_TRIAL_DAYS` |
| قیمت ماهانه | ۹۹٬۰۰۰ تومان | `ARIA_MONTHLY_PRICE_TOMAN` |
| درگاه پرداخت | زرین‌پال | `ZARINPAL_MERCHANT_ID` + `ARIA_PUBLIC_BASE_URL` |
| محدودیت مهمان | روزانه | داخل cloud |
| ساخت تصویر/کلیپ | جدا و قابل خاموش | `ARIA_MEDIA_ENABLED` |

## مسیر عملی کسب درآمد

1. **سرور ابری داخل ایران** (Weblines یا مشابه) با دامنه HTTPS
2. کلید **1xAi** یا **AvalAI** بگذار (اعتبار اولیه رایگان/ارزان)
3. `ZARINPAL_SANDBOX=false` و Merchant ID واقعی
4. اپ را در **کافه‌بازار** و **مایکت** منتشر کن (نسخه بتا رایگان + اشتراک داخل‌اپ)
5. Owner (خودت) رایگان بماند (`ARIA_OWNER_EMAIL`)

## توصیه‌های قیمت‌گذاری ایران

- Trial ۳۰ روزه جذاب است → تبدیل بالا
- ۹۹ هزار تومان ماهانه برای دستیار شخصی + صوت فارسی منطقی است
- بعداً پلن سالانه (مثلاً ۸۹۰ هزار) اضافه کن
- ساخت تصویر/کلیپ را جدا یا فقط برای پلن پولی باز بگذار

## کارهای باقی‌مانده برای لانچ پولی

- [ ] دامنه HTTPS واقعی
- [ ] Merchant ID زرین‌پال live
- [ ] تست پرداخت واقعی با مبلغ کم
- [ ] انتشار APK در کافه‌بازار / مایکت
- [ ] متن قوانین و حریم خصوصی فارسی
- [ ] پشتیبانی تلگرام یا ایمیل

ARIA آماده مدل درآمدی است؛ فقط کلیدها و انتشار فروشگاهی باقی مانده.


## محدودیت روزانه پیشنهادی (برای سود بیشتر)

| نوع | رایگان / Trial | اشتراک پولی | چرا |
|-----|----------------|-------------|-----|
| چت روزانه | **۶** | **۸۰** | رایگان کم → تبدیل بالاتر |
| تصویر روزانه | **۰** | **۸** | فقط پولی → ارزش اشتراک |
| کلیپ روزانه | **۰** | **۲** | هزینه بالا، محدود نگه دار |

تنظیم در `.env`:

```env
ARIA_DAILY_FREE_CHAT_LIMIT=6
ARIA_DAILY_PAID_CHAT_LIMIT=80
ARIA_DAILY_FREE_IMAGE_LIMIT=0
ARIA_DAILY_PAID_IMAGE_LIMIT=8
ARIA_DAILY_FREE_VIDEO_LIMIT=0
ARIA_DAILY_PAID_VIDEO_LIMIT=2
```

اگر دیدی کاربران زود به سقف می‌خورند و ناراضی‌اند، paid را به ۱۰۰–۱۲۰ برسان.
اگر هزینه API بالا رفت، free را به ۴ و paid را به ۶۰ کاهش بده.
