# راه‌اندازی ARIA برای کاربران ایران

**راهنمای اجرایی فعلی:** [اتصال ARIA به نِت‌اَرز / گیسو](netarz-integration-fa.md)

نسخهٔ فعلی کد ARIA از درگاه نِت‌اَرز با آدرس ویژهٔ ایران استفاده می‌کند:
`https://ir.gisoo.pro/api/v1`

این یکپارچه‌سازی از یک کلید API برای چت، فهرست زندهٔ مدل‌ها، تولید تصویر و رندر ویدئو استفاده می‌کند. برای فعال‌شدن واقعی، باید کلید API در Secretهای سرور و دامنهٔ HTTPS در تنظیمات Android ثبت شود. تا پیش از آن، خالی‌بودن آدرس سرور یا تنظیم‌نشدن API key باعث می‌شود چت پاسخ ندهد.

هزینهٔ اولیه API رایگان یا نامحدود نیست؛ مدل‌های رایگان فعلاً ارائه نمی‌شوند و حداقل شارژ اعلام‌شده ۵۰٬۰۰۰ تومان است. ویدئو به‌ازای ثانیه هزینه دارد، بنابراین ابتدا فقط چت را تست کن و رسانه را خاموش نگه دار.

میزبانی پیشنهادی برای بازار ایران: Weblines یا VPS داخلی با Docker، دامنهٔ HTTPS و Volume پایدار به مسیر `/data`. قیمت و شرایط میزبانی را پیش از خرید در سایت رسمی بررسی کن:
https://www.weblines.ir/pricing

**درآمدزایی:** کد اشتراک و callback زرین‌پال وجود دارد، اما فعال‌بودن کد به معنی فعال‌بودن پرداخت نیست. تا وقتی Merchant ID واقعی، دامنه، callback و یک پرداخت آزمایشی/واقعی با موفقیت بررسی نشده‌اند، از کاربر پول نگیر.

جزئیات کامل و متغیرهای محیطی در [راهنمای NetArz](netarz-integration-fa.md) است.
