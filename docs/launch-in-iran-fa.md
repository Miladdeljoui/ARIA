# راه‌اندازی ARIA برای کاربران ایران

این راهنما وضعیت واقعی نسخهٔ فعلی را از مواردی که هنوز به حساب و کلید مالک نیاز دارند جدا می‌کند.

## معماری انتخاب‌شده

- **چت و فهرست مدل‌ها:** 1xAi با API سازگار با OpenAI. یک کلید API، مدل‌های چند ارائه‌دهنده را در اختیار سرور ARIA می‌گذارد. اپ فقط به سرور خود ARIA وصل می‌شود و کلید 1xAi داخل APK قرار نمی‌گیرد.
- **ساخت تصویر:** مسیر Images در همان API یکپارچهٔ 1xAi.
- **ساخت کلیپ:** API جداگانهٔ AvalAI؛ کلید ویدئو باید جداگانه روی سرور نگهداری شود.
- **سرور:** یک VPS کوچک بدون GPU. پردازش مدل در سرویس‌های API انجام می‌شود، نه روی VPS.

مراجع رسمی:
- 1xAi API و فهرست زندهٔ مدل‌ها: https://1xai.ir/en/docs
- 1xAi endpoint سازگار با OpenAI: https://1xai.ir/en/openai-compatible-endpoint
- AvalAI Video API: https://docs.avalai.org/en/api-reference/videos
- راهنمای مدل و قیمت ویدئو: https://docs.avalai.org/en/guides/generate-videos-using-veo

## نکات هزینه و دسترسی

1xAi طبق مستندات فعلی از شبکهٔ ایران قابل دسترسی معرفی شده و پرداخت کیف پول API با تومان انجام می‌شود. برای ساخت کلید باید حساب بسازی و پروفایل هویتی خود سرویس را تکمیل کنی. اعتبار هدیهٔ ثبت‌نام محدود و دارای مهلت است؛ API رایگان نامحدود نیست و مصرف پس از تمام‌شدن اعتبار از کیف پول کم می‌شود. اعتبار طرح رایگان وب‌چت را با اعتبار API اشتباه نگیر.

برای ویدئو، مدل `veo-3.1-fast-generate-001` در مستندات AvalAI حدود ۰٫۱۵ دلار به‌ازای هر ثانیه اعلام شده است؛ یک کلیپ ۴ ثانیه‌ای تقریباً ۰٫۶۰ دلار می‌شود. هزینهٔ نهایی تومانی به نرخ تبدیل و تعرفهٔ روز حساب بستگی دارد. برای شروع، ویدئو را خاموش نگه دار.

## VPS پیشنهادی برای شروع

صفحهٔ قیمت Bia2Host در زمان بررسی این گزینه‌ها را نمایش می‌داد:
- پلن ایران ۲ گیگابایت RAM، دو هسته CPU و ۱۵ گیگابایت دیسک، حدود ۴۹۰٬۰۰۰ تومان در ماه برای طرح ترافیک نامحدود.
- نسخهٔ ترافیکی ۲ گیگابایت RAM و دو هسته CPU با ۵۰ گیگابایت ترافیک اولیه، حدود ۵۴۰٬۰۰۰ تومان در ماه.

لینک: https://bia2host.com/iran-vps/

**قبل از خرید** از پشتیبانی فروشنده کتبی بپرس:
1. IPv4 عمومی و قابل اتصال برای دامنه می‌دهد یا فقط IPv6؟ اگر IPv4 جداگانه است، قیمت نهایی آن چقدر است؟
2. Docker و دسترسی root/SSH مجاز است؟
3. ارتباط خروجی HTTPS از همان VPS به `https://1xai.ir` و `https://api.avalai.ir` باز است؟
4. پورت‌های ۸۰ و ۴۴۳ برای Caddy و گواهی HTTPS آزادند؟
5. Volume یا دیسک پایدار برای فایل `/data/aria_cloud.db` وجود دارد؟
6. در صورت مسدودبودن مسیر API، مهلت تست یا بازگشت وجه دارد؟

قیمت، IP و مسیر بین‌الملل را قبل از پرداخت نهایی در صفحهٔ سفارش کنترل کن. انتخاب پلن «ترافیک نامحدود» لزوماً به معنی سرعت دانلود نامحدود از خارج نیست؛ صفحهٔ فروشنده برای دانلود بین‌الملل سقف سرعت جداگانه ذکر می‌کند.

## آماده‌سازی حساب‌های API

### ۱) 1xAi برای چت و تصویر

1. در https://1xai.ir/en ثبت‌نام کن.
2. پروفایل هویتی را در خود پنل کامل کن.
3. موجودی هدیه، تاریخ انقضا و نرخ مدل را در داشبورد بررسی کن.
4. یک API key بساز و فقط روی VPS در فایل خصوصی `.env` قرار بده. کلید را در GitHub، APK، تلگرام یا چت ارسال نکن.

### ۲) AvalAI برای ویدئو

1. در https://chat.avalai.ir حساب توسعه‌دهنده بساز.
2. قیمت فعلی مدل و سقف هزینه را در داشبورد بررسی کن.
3. کلید API را در `ARIA_VIDEO_API_KEY` روی VPS قرار بده.
4. تا قبل از تست هزینه و محدودیت حساب، `ARIA_MEDIA_ENABLED=false` بماند.

## استقرار روی VPS

پس از خرید VPS و تنظیم DNS دامنه، با SSH وارد سرور شو. در مثال زیر، دامنه را با دامنهٔ واقعی خودت جایگزین کن:

```bash
sudo apt update && sudo apt install -y git docker.io docker-compose-plugin
sudo systemctl enable --now docker
git clone https://github.com/Miladdeljoui/ARIA.git
cd ARIA/cloud
cp .env.example .env
nano .env
```

در فایل `.env`:
- `ARIA_API_KEY`: کلید خصوصی 1xAi.
- `ARIA_VIDEO_API_KEY`: کلید خصوصی AvalAI برای ویدئو.
- `ARIA_PUBLIC_BASE_URL`: نشانی HTTPS واقعی، مثلاً `https://api.your-domain.ir`.
- `ARIA_MEDIA_ENABLED=false`: فعلاً خاموش بماند.
- `ZARINPAL_SANDBOX=true`: تا زمان تست درگاه واقعی روشن بماند.

در فایل `cloud/Caddyfile` دامنهٔ واقعی را جایگزین مقدار نمونه کن. سپس:
```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
docker compose -f docker-compose.remote.yml up -d --build
```

پورت ۸۰۰۰ را مستقیم روی اینترنت باز نکن؛ Caddy باید HTTPS را مدیریت کند. فایل پایگاه داده باید روی Volume پایدار `/data` باشد.

## اتصال اپ

در نسخهٔ فعلی، فرم نام/شمارهٔ مهمان و قفل محلی PIN/عبارت صوتی حذف شده است. هر نصب پس از تعیین سرور، به‌صورت خودکار توکن مهمان می‌گیرد. آدرس قبلی Weblines عمداً به‌عنوان پیش‌فرض حذف شده، چون نباید APK را به یک آدرس تأییدنشده متصل کنیم.

بعد از استقرار، در ARIA → تنظیمات، آدرس کامل HTTPS سرور را وارد کن، مثلاً:
`https://api.your-domain.ir`

سپس «اتصال مجدد به سرور» را بزن. برای تست سلامت:
`https://api.your-domain.ir/status`

در پاسخ باید `cloud_ai_configured: true` و `chat_ready: true` دیده شود. در مدل‌ها، ARIA اکنون تلاش می‌کند فهرست زندهٔ `/v1/models` را از 1xAi بگیرد؛ اگر آن سرویس موقتاً در دسترس نباشد از فهرست کش‌شده استفاده می‌کند.

## درآمدزایی: نسخهٔ آزمایشی، نه دریافت پول فوری

کد سرور مسیر اشتراک و callback زرین‌پال را دارد، اما تا وقتی دامنهٔ واقعی، Merchant ID، تنظیمات production، backup و تست برگشت از درگاه فراهم نشده باشد پرداخت واقعی فعال نیست. مقدار فعلی نمونه در تنظیمات، ۹۹٬۰۰۰ تومان برای ماهانه و ۳۰ روز آزمایشی است؛ این قیمت را پیش از عرضه با بهای هر مدل و هزینهٔ رسانه مقایسه کن.

**فروش اشتراک نامحدود با قیمت ثابت برای مدل‌های گران و تولید ویدئو خطر زیان دارد.** پیشنهاد شروع:
- پلن رایگان با سقف پایین چت و بدون ویدئو.
- بستهٔ اعتباری یا سقف مصرف برای چت مدل‌های گران.
- تصویر با سهمیهٔ روزانهٔ جداگانه.
- ویدئو فقط با اعتبار جداگانه و نمایش هزینه پیش از تولید.
- لاگ مصرف، نرخ هر مدل، سقف روزانه/ماهانه و هشدار کیف پول در سمت سرور.

در حال حاضر محدودیت‌های درخواست در سرور وجود دارد، اما سقف تعداد درخواست به‌تنهایی معادل سقف ریالی نیست. پیش از گرفتن پول از کاربر، حسابداری هزینه و شارژ اعتبار باید کامل و با چند تراکنش آزمایشی تأیید شود.

## مواردی که هنوز به اقدام مالک نیاز دارند

- خرید VPS و دامنه و تنظیم DNS.
- ساخت و ثبت کلیدهای 1xAi و AvalAI در VPS (نه ارسال آن‌ها به گفتگو).
- تست اتصال خروجی VPS به هر دو سرویس و تست چت با گوشی واقعی.
- دریافت Merchant ID و فعال‌سازی production زرین‌پال پس از تست callback.
- تست یک تصویر و یک کلیپ با اعتبار کم، پس از آن فعال‌کردن رسانه.

این پروژه نباید به مشتری فروخته شود تا زمانی که تست چت، هزینهٔ API، حریم خصوصی، پرداخت و بازیابی اطلاعات با موفقیت انجام شده باشد.
