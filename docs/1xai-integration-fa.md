# اتصال ARIA به 1xAi برای کاربران ایران

وضعیت: کد اتصال و انتخاب مدل اضافه شده است؛ اتصال واقعی فقط بعد از ثبت کلید در Secretهای Weblines و Deploy سرویس فعال می‌شود.

## چرا 1xAi؟

1xAi یک درگاه سازگار با OpenAI است. با یک کلید و آدرس `https://1xai.ir/v1` می‌توان مدل‌های OpenAI، Anthropic/Claude، Google/Gemini، DeepSeek، xAI/Grok، Moonshot/Kimi، Z.ai/GLM، Qwen، MiniMax و Tencent/Hunyuan را فراخوانی کرد. مسیر چت مورد استفادهٔ ARIA:

`POST https://1xai.ir/v1/chat/completions`

مسیر فهرست مدل‌ها:

`GET https://1xai.ir/v1/models`

مرجع‌ها:
- https://1xai.ir/en/docs
- https://1xai.ir/en/openai-compatible-endpoint
- https://1xai.ir/models
- https://1xai.ir/status
- https://1xai.ir/terms

1xAi سرویس مستقل و واسط API است، نه محصول یا نمایندهٔ OpenAI، Anthropic، Google یا شرکت‌های مدل. پیام‌ها برای ارائهٔ پاسخ به سرویس‌دهندهٔ انتخاب‌شده منتقل می‌شوند و سیاست‌های همان سرویس‌دهنده هم اعمال می‌شود.

## شروع حساب و دریافت کلید

1. در https://1xai.ir/ حساب بساز.
2. پروفایل هویتی در پنل خود سرویس تکمیل شود؛ مستندات 1xAi می‌گوید بدون تکمیل پروفایل، ساخت کلید و استفاده از API ممکن است با HTTP 428 رد شود.
3. از پنل، یک کلید API با پیشوند `1xai-` صادر کن و همان لحظه در محل امن نگه دار.
4. هرگز کلید را در تلگرام، APK، سورس GitHub یا پیام عمومی قرار نده.

اعتبار خوش‌آمدگویی رایگانِ نامحدود نیست: خود 1xAi برای حساب تازه، گردونهٔ هدیه با اعتبار محدود و مهلت ۱۴ روزه اعلام کرده است؛ اعتبار مدل‌های کم‌هزینه و اعتبار عمومی شرایط جدا دارند. پیش از استفاده از API، مقدار هدیه، مدل‌های مجاز و تاریخ انقضایش را در داشبورد خودت چک کن.

## تنظیمات سرور

در Weblines، سرویس موجود ARIA را با Dockerfile در `cloud/Dockerfile` و Build context برابر `cloud` Deploy کن. پورت کانتینر `8000` و Health check برابر `/status` است. یک Volume پایدار به `/data` وصل کن.

متغیرهای زیر را در Environment/Secrets سرور ثبت کن:

```dotenv
ARIA_HOST=0.0.0.0
ARIA_PORT=8000
ARIA_PROVIDER=1xai
ARIA_API_BASE_URL=https://1xai.ir/v1/chat/completions
ARIA_API_KEY=کلید_خصوصی_1xAi
ARIA_MODEL=deepseek-v4-flash
ARIA_ALLOWED_MODELS=deepseek-v4-flash,deepseek-chat,gemini-2.5-flash-lite,gpt-5-mini,claude-haiku-4-5,qwen3.8-flash,kimi-k2.6,glm-5.3-flash,MiniMax-M3.1-Flash

ARIA_IMAGE_API_URL=https://1xai.ir/v1/images/generations
ARIA_IMAGE_MODEL=gpt-image-2
ARIA_MEDIA_ENABLED=false

# ساخت کلیپ با 1xAi در API عمومی مستند نشده است.
# در صورت انتخاب ارائه‌دهندهٔ ویدئوی جداگانه، کلید و endpoint مخصوص همان ارائه‌دهنده را تنظیم کن:
ARIA_VIDEO_API_URL=
ARIA_VIDEO_API_KEY=
ARIA_VIDEO_MODEL=veo-3.1-fast-generate-001

ARIA_DB=/data/aria_cloud.db
ARIA_OWNER_NAME=Milad
ARIA_TRIAL_DAYS=30
ARIA_MONTHLY_PRICE_TOMAN=99000
ARIA_PUBLIC_BASE_URL=https://aria-2.weblines.ir
ZARINPAL_SANDBOX=true
ZARINPAL_MERCHANT_ID=
```

اگر می‌خواهی مدل پیش‌فرض را عوض کنی، `ARIA_MODEL` را تغییر بده. برای اجازه‌دادن یا محدودکردن مدل‌های قابل انتخاب در اپ، فهرست `ARIA_ALLOWED_MODELS` را تنظیم کن. فعلاً فهرست محدود است تا حساب API با انتخاب ناخواستهٔ مدل گران خالی نشود.

## ساخت تصویر

1xAi مسیر OpenAI-compatible برای `/v1/images/generations` را مستند کرده است. مدل `gpt-image-2` خروجی base64 می‌دهد و ARIA آن را داخل گفت‌وگو نمایش می‌دهد. اعتبار هدیهٔ چت را با اعتبار تصویر اشتباه نگیر؛ صفحهٔ راهنمای تصویر 1xAi برای تولید عکس شارژ کیف پول را لازم می‌داند.

تا وقتی موجودی و سقف مصرف را تعیین نکرده‌ای، `ARIA_MEDIA_ENABLED=false` بماند. بعد از تست موفق با یک تصویر کم‌هزینه، آن را آگاهانه روشن کن.

## ساخت کلیپ

در مرجع API عمومی 1xAi که بررسی شد، مسیرهای چت، مدل‌ها، تصویر و صوت مستند شده‌اند؛ endpoint عمومی و مستند ویدئو در این مرجع دیده نشد. پس ARIA نباید ادعا کند یک کلید 1xAi به‌تنهایی کلیپ می‌سازد. قابلیت کلیپ در کد سرور موجود است، اما برای فعال‌سازی به کلید جداگانه و endpoint معتبر ارائه‌دهندهٔ ویدئو نیاز دارد. تا پیش از آن، گزینهٔ کلیپ باید خطای واضح «سرویس ویدئو پیکربندی نشده» بدهد، نه اینکه درخواست را به کلید 1xAi بفرستد.

## انتخاب مدل در برنامه

اپ از `GET /models` سرور ARIA فهرست مجاز را دریافت می‌کند. انتخاب کاربر در SharedPreferences ذخیره و همراه هر پیام به `POST /chat` ارسال می‌شود. سرور مدل انتخابی را در برابر allowlist بررسی می‌کند و فقط همان مدل‌های مجاز را می‌پذیرد. کلید 1xAi هرگز به APK فرستاده نمی‌شود.

## پلن میزبانی پیشنهادی

قیمت عمومی فعلی Weblines (پرداخت ساعتی، اعداد صفحهٔ قیمت؛ مصرف ۷۲۰ ساعت در ماه برآورد شده):

| پلن | منابع | ساعتی | ماهانهٔ تقریبی |
|---|---|---:|---:|
| Nano | 250m CPU، 512MB RAM، 1GB disk | 431 تومان | 310,320 تومان |
| Micro | 500m CPU، 1GB RAM، 5GB disk | 931 تومان | 670,320 تومان |
| Small | 1 vCPU، 2GB RAM، 10GB disk | 1,862 تومان | 1,340,640 تومان |

برای نمونهٔ اولیه، Micro متعادل‌تر است. Nano ارزان‌تر است، ولی فقط برای تست با ترافیک بسیار کم. برای چند کاربر هم‌زمان و فایل‌های رسانه، بعد از مشاهدهٔ Metrics ممکن است Small لازم شود. Weblines اعتبار خوش‌آمدگویی دارد، ولی مقدار و شرایط آن را هنگام ثبت‌نام بررسی کن. هزینهٔ API مدل و ساخت تصویر/ویدئو جدا از هزینهٔ میزبانی است.

سایت و قیمت‌ها: https://www.weblines.ir/

## درآمدزایی و ایمنی انتشار

در کد ARIA مسیر اشتراک و callback زرین‌پال وجود دارد، اما تا تنظیم پذیرندهٔ واقعی، Deploy دامنهٔ HTTPS، تست sandbox و یک تراکنش کم‌مبلغ واقعی، پرداخت را فعال یا تبلیغ نکن. قیمت فعلی نمونه در تنظیمات سرور ۹۹٬۰۰۰ تومان در ماه و دورهٔ آزمایشی ۳۰ روز است؛ این قیمت باید با هزینهٔ هر پیام، تصویر، ویدئو، میزبانی و پشتیبانی مقایسه شود.

پیش از فروش عمومی:
- هزینهٔ API را برای هر حساب و هر مدل سقف‌گذاری کن.
- سهمیهٔ رایگان را از سهمیهٔ پولی جدا کن و لاگ مصرف داشته باش.
- مالکیت حساب، جلوگیری از ساخت حساب تکراری و بازیابی حساب را واقعی پیاده کن؛ شناسهٔ نصب به‌تنهایی احراز هویت قوی نیست.
- سیاست حریم خصوصی، شرایط استفاده، لغو، بازپرداخت و راه پشتیبانی منتشر شود.
- تست واقعی روی گوشی و شبکهٔ ایران انجام شود.

ساخت APK یا سبزشدن CI به معنی Deploy سرور، شارژ 1xAi، فعال‌شدن تولید رسانه یا آماده‌بودن فروش نیست.
