# یکپارچه‌سازی قدیمی 1xAi با ARIA

این سند برای سوابق قبلی پروژه نگهداری شده است. **در نسخهٔ جاری، درگاه پیش‌فرض ایران NetArz / Gisoo است.** راهنمای جدید، endpointها، کلید، مدل‌ها، تصویر، ویدئو و استقرار را در [docs/netarz-integration-fa.md](netarz-integration-fa.md) ببین.

تنظیمات قدیمی 1xAi را با تنظیمات NetArz مخلوط نکن. برای محیط تازه از فایل `cloud/.env.example` استفاده کن. کلید API باید فقط در Secretهای سرور ذخیره شود، نه در APK یا GitHub.
