# اتصال رایگان اولیهٔ ARIA به مدل‌های هوش مصنوعی

این مسیر برای آزمایش است؛ هیچ کلید API داخل APK ذخیره نمی‌شود.

## راه‌اندازی سرور آزمایشی

1. در [OpenRouter](https://openrouter.ai/keys) حساب بساز و یک API key ایجاد کن. مدل‌های رایگان با مدل‌گردان `openrouter/free` انتخاب می‌شوند؛ سهمیه محدود است و عملکرد/دسترسی همیشگی تضمین نمی‌شود.
2. [ARIA را در Render مستقر کن](https://render.com/deploy?repo=https://github.com/Miladdeljoui/ARIA). Blueprint از فایل `render.yaml` استفاده می‌کند.
3. هنگام استقرار، مقدار `ARIA_API_KEY` را فقط در قسمت Environment/Secret وارد کن. این مقدار نباید در GitHub، APK یا چت عمومی قرار بگیرد. `ARIA_MODEL` باید `openrouter/free` باقی بماند.
4. پس از تکمیل استقرار، آدرس عمومی سرویس Render را بردار و در ARIA ← تنظیمات ← آدرس سرور ARIA وارد کن. سپس «اتصال مجدد به سرور» را بزن.
5. در آدرس `https://نام-سرویس.onrender.com/status` باید `cloud_ai_configured: true` دیده شود. سپس یک پیام کوتاه در اپ بفرست.

## محدودیت‌های رایگان

- سرور رایگان Render بعد از ۱۵ دقیقه بی‌فعالیتی خاموش می‌شود و اولین درخواست بعدی ممکن است حدود یک دقیقه طول بکشد. فایل SQLite روی سرویس رایگان پایدار نیست؛ برای آزمایش مناسب است، نه سرویس عمومی قابل اتکا.
- OpenRouter رایگان محدودیت درخواست و در دسترس‌بودن مدل دارد. این ترکیب برای تست و استفادهٔ سبک است، نه چت نامحدود یا تضمین‌شده.
- ساخت تصویر و به‌ویژه ویدئو رایگان تضمین نمی‌شود. این پروژه آن را در سرور خاموش نگه می‌دارد (`ARIA_MEDIA_ENABLED=false`) تا اعتبار ناخواسته مصرف نشود. فقط بعد از بررسی قیمت و تعیین بودجه، آن را در تنظیمات سرور فعال کن.
- برای سرویس عمومی دائمی، از VPS ارزان اروپایی استفاده کن و دیتابیس پایدار داشته باش. در VPS فقط خودِ درگاه API اجرا می‌شود؛ GPU لازم نیست چون تولید متن در OpenRouter انجام می‌شود.

## عیب‌یابی سریع

- `cloud_ai_configured: false`: کلید `ARIA_API_KEY` تنظیم نشده یا سرویس پس از تغییر Environment دوباره deploy نشده.
- `404` هنگام اتصال مهمان: نسخهٔ قدیمی سرور مستقر است. از آخرین شاخهٔ `main` دوباره deploy کن.
- `429`: سهمیهٔ رایگان مدل یا سقف استفادهٔ ARIA تمام شده.
- اگر نسخهٔ قدیمی اپ هنوز کد ۶ رقمی نشان می‌دهد، آن را حذف و APK نسخهٔ جدید را نصب کن؛ نسخهٔ فعلی از اتصال مهمان خودکار استفاده می‌کند.
