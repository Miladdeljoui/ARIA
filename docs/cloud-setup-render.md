# راه‌اندازی ابری آزمایشی ARIA با AvalAI

این راه‌اندازی برای آزمایش اولیه است. کلید سرویس‌دهنده فقط باید در متغیر محرمانهٔ سرور ثبت شود؛ هرگز آن را در APK، GitHub یا گفت‌وگوی عمومی قرار نده.

## موتور مدل‌ها

1. در [داشبورد AvalAI](https://chat.avalai.ir/) حساب ایجاد کن و API Key بساز.
2. مستندات AvalAI از API سازگار با OpenAI و دسترسی یکپارچه به مدل‌های ارائه‌دهندگان گوناگون پشتیبانی می‌کند. برای کاربران داخل ایران، دامنهٔ `https://api.avalai.ir` مسیر داخلی پیشنهادی مستندات است. در صورت اختلال، دامنهٔ جایگزین مستندشدهٔ `https://api.avalapis.ir` را بررسی کن.
3. طبق مستندات فعلی، با تأیید شماره تا ۲۰۰٬۰۰۰ تومان اعتبار اولیهٔ API اعلام شده است؛ اعتبار هدیه محدود است و سرویس رایگان نامحدود نیست. موجودی و شرایط لحظه‌ای را داخل حساب بررسی کن.
4. در سرور فقط این مقادیر را تنظیم کن:

```dotenv
ARIA_PROVIDER=avalai
ARIA_API_BASE_URL=https://api.avalai.ir/v1/chat/completions
ARIA_API_KEY=کلید_خصوصی_تو
ARIA_MODEL=gpt-5.4-nano
ARIA_IMAGE_API_URL=https://api.avalai.ir/v1/images/generations
ARIA_IMAGE_MODEL=gpt-image-2.5-flare
ARIA_VIDEO_API_URL=https://api.avalai.ir/v1/videos
ARIA_VIDEO_MODEL=veo-3.1-fast-generate-001
ARIA_MEDIA_ENABLED=false
```

مستندات و قیمت‌ها:
- API و فهرست مدل‌ها: https://docs.avalai.org/fa/quickstart
- دامنه‌های API داخل ایران و خارج: https://docs.avalai.org/en/news/2025-06-15-expanded-api-access-domains
- تولید تصویر: https://docs.avalai.org/fa/api-reference/images
- تولید ویدئو: https://docs.avalai.org/fa/guides/generate-videos-using-veo
- قیمت‌گذاری: https://docs.avalai.org/fa/pricing

## سرور آزمایشی Render

Render رایگان فقط برای تست اولیه مناسب است:
1. [استقرار مخزن ARIA در Render](https://render.com/deploy?repo=https://github.com/Miladdeljoui/ARIA) را باز کن.
2. مقدار `ARIA_API_KEY` را فقط در قسمت Environment/Secret ثبت کن.
3. پس از استقرار، آدرس Render را در ARIA ← تنظیمات ← آدرس سرور وارد کن.
4. `/status` باید `cloud_ai_configured: true` و `ai_provider: "avalai"` نشان بدهد.

Render رایگان ممکن است پس از دورهٔ بی‌فعالیتی به خواب برود و فضای فایل موقت آن پایدار نیست؛ برای دیتابیس کاربران و برنامهٔ درآمدی مناسب نیست. برای استفادهٔ عمومی باید VPS دارای فضای پایدار و نسخهٔ پشتیبان راه‌اندازی شود.

## تصویر و کلیپ

ساخت رسانه پیش‌فرض خاموش است. یک تصویر 1024×1024 با کیفیت medium از مدل `gpt-image-2.5-flare` حدود ۰٫۰۱۳۱۷ دلار قیمت درج‌شده دارد، به‌علاوه هزینهٔ ورودی احتمالی. مدل سریع Veo 3.1 طبق مستندات ۰٫۱۵ دلار به‌ازای ثانیه است؛ یک کلیپ ۴ ثانیه‌ای حدود ۰٫۶۰ دلار می‌شود. قبل از فعال‌سازی، قیمت و موجودی زنده را بررسی کن و سقف هزینهٔ سرویس‌دهنده را تنظیم کن.

## سرور پایدار و اقتصادی

برای سرویس API به GPU نیاز نیست؛ VPS فقط درگاه امن ARIA را اجرا می‌کند و محاسبات متن/تصویر/ویدئو در ارائه‌دهندهٔ مدل انجام می‌شود. پیش از خرید VPS از شرکت میزبان تأیید بگیر:
- Docker و SSH/root در دسترس باشد.
- IPv4 عمومی، دامنه و HTTPS داشته باشد.
- از VPS بتوان به `api.avalai.ir` روی HTTPS وصل شد.
- فضای پایدار و بکاپ برای `/data/aria_cloud.db` ارائه شود.

## تست پس از استقرار

1. آدرس `https://دامنه-تو/status` را باز کن.
2. از داخل اپ یک پیام فارسی کوتاه در حالت چت بفرست.
3. تولید تصویر را فقط با یک درخواست و بودجهٔ کم امتحان کن.
4. ساخت یک کلیپ ۴ ثانیه‌ای را بعد از بررسی قیمت آزمایش کن.

کد مهمان ARIA بدون کد شش‌رقمی کار می‌کند؛ نسخهٔ تازهٔ APK را نصب کن تا تغییرات کلاینت را دریافت کنی. پرداخت اشتراک و مالکیت حساب گوگل هنوز نیازمند پیاده‌سازی و آزمون مستقل است؛ تا آن زمان از کاربران پول نگیر.
