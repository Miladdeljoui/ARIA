# امنیت: کد و رمز روی GitHub نرود

## قانون

**کد جفت‌سازی، PIN مالک، توکن دستگاه، و فایل state هرگز commit نشوند.**

## فایل‌های محلی (در `.gitignore`)

| فایل | محتوا |
|------|--------|
| `aria_state.json` | هش کد pairing + توکن دستگاه‌ها |
| `aria_memory.db` | حافظه و درس‌ها |
| `aria_learn_queue.json` | صف خودآموزی |
| `.env` | رمز و متغیرهای محیطی |

## کجا کد/رمز می‌ماند؟

- **کد ۶ رقمی pairing:** فقط روی ترمینال لپ‌تاپ وقتی `python aria_server.py` اجرا می‌شود
- **PIN و عبارت صوتی:** فقط روی گوشی (`OwnerLock`)
- **توکن وب:** فقط `localStorage` مرورگر تو

## کار درست بعد از دیدن کد در ترمینال

1. کد را در اپ/وب وارد کن
2. آن را در چت عمومی، Issue گیت‌هاب، یا README نگذار
3. اگر لو رفت: `aria_state.json` را پاک کن و سرور را دوباره اجرا کن تا کد جدید ساخته شود

## اگر اشتباهاً secret روی GitHub رفت

1. فایل را از تاریخچه پاک کن / state را عوض کن
2. کد pairing را عوض کن (حذف `aria_state.json`)
3. توکن‌های دستگاه را از نو جفت کن
