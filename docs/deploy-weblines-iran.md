# استقرار نسخهٔ ابری ARIA روی Weblines برای کاربران ایران

این راهنما برای اجرای backend جدید FastAPI در مسیر `cloud/aria_cloud.py` است. دامنهٔ فعلی اپ، `https://aria-2.weblines.ir`، فقط وقتی درست کار می‌کند که همین سرویس ابری روی آن مستقر شده باشد؛ نسخهٔ قدیمی `server/aria_server.py` با همهٔ مسیرهای رسانه‌ای اپ یکسان نیست.

## 1) پیش‌نیازها

- یک حساب Weblines Cloud و یک سرویس Docker در منطقهٔ در دسترس.
- حساب AvalAI و یک API Key فعال. کلید را در پیام، APK یا فایل GitHub قرار نده.
- یک Volume پایدار برای پایگاه‌داده؛ SQLite نباید روی فضای موقت کانتینر بماند.

مخزن: https://github.com/Miladdeljoui/ARIA

## 2) تنظیم سرویس Weblines

در Weblines یک سرویس از مخزن GitHub بساز و این موارد را تنظیم کن:

| فیلد | مقدار |
|---|---|
| Repository | `Miladdeljoui/ARIA` |
| Branch | `main` |
| Build method | Dockerfile |
| Dockerfile path | `cloud/Dockerfile` |
| Build context | `cloud` |
| Container port | `8000` |
| Health check | `/status` |

اگر Weblines فقط مسیر Dockerfile می‌خواهد، همان `cloud/Dockerfile` را انتخاب کن و context را `cloud` بگذار.

## 3) متغیرهای محیطی (Environment / Secrets)

این‌ها را در پنل سرویس تنظیم کن:

```dotenv
ARIA_HOST=0.0.0.0
ARIA_PORT=8000
ARIA_PROVIDER=avalai
ARIA_API_BASE_URL=https://api.avalai.ir/v1/chat/completions
ARIA_API_KEY=کلید_خصوصی_AvalAI
ARIA_MODEL=deepseek-flash

ARIA_IMAGE_API_URL=https://api.avalai.ir/v1/images/generations
ARIA_IMAGE_MODEL=muse-image-1.0
ARIA_VIDEO_API_URL=https://api.avalai.ir/v1/videos
ARIA_VIDEO_MODEL=veo-3.1-fast-generate-001
ARIA_MEDIA_ENABLED=false

ARIA_DB=/data/aria_cloud.db
ARIA_OWNER_NAME=Milad
ARIA_TRIAL_DAYS=30
ARIA_MONTHLY_PRICE_TOMAN=99000
ARIA_PUBLIC_BASE_URL=https://aria-2.weblines.ir
ZARINPAL_SANDBOX=true
ZARINPAL_MERCHANT_ID=کلید_پذیرنده_درگاه
```

**مهم:** `ARIA_API_KEY` را به‌عنوان Secret ثبت کن. آن را در GitHub commit نکن. تا وقتی حساب AvalAI شارژ نشده و سقف هزینه را تعیین نکرده‌ای، `ARIA_MEDIA_ENABLED=false` باقی بماند.

## 4) ذخیره‌سازی پایدار

در پنل Weblines یک Volume بساز و آن را در مسیر `/data` متصل کن. مسیر دیتابیس باید دقیقاً `/data/aria_cloud.db` باشد. اگر Volume نداری، با ری‌استارت یا استقرار مجدد ممکن است داده‌های کاربران و گفت‌وگوها از بین بروند؛ برای محصول عمومی این وضعیت قابل قبول نیست.

## 5) دامنه و HTTPS

دامنهٔ سرویس را به `aria-2.weblines.ir` متصل کن یا دامنهٔ تولیدشدهٔ Weblines را بردار. HTTPS باید فعال باشد. بعد از Deploy این نشانی را در مرورگر باز کن:

- `https://دامنه-سرویس/status`

پاسخ سالم باید دست‌کم این وضعیت‌ها را نشان دهد:

- `cloud_ai_configured: true`
- `chat_ready: true`
- `api_provider: "avalai"`
- `api_model: "deepseek-flash"`

بعد در اپ از مسیر تنظیمات، همان دامنه را در «آدرس سرور ARIA» ذخیره و «اتصال مجدد» را بزن. سپس یک پیام کوتاه فارسی بفرست.

## 6) مسیرهای رسانه

- متن: `POST /chat`
- عکس: `POST /media/image`
- کلیپ: `POST /media/video`

ساخت رسانه هزینهٔ جداگانه دارد و نباید به‌عنوان «رایگان نامحدود» تبلیغ شود. در نسخهٔ فعلی، کلید و اعتبار سرویس‌دهنده باید روی سرور باشد. سهمیهٔ چت: ۱۰ پیام روزانه برای دورهٔ آزمایشی و ۱۰۰ پیام روزانه برای اشتراک پرداخت‌شده، با سقف محافظتی ۲۵۰ پیام برای کل سرویس در روز. سهمیهٔ رسانه: حداکثر ۳ تلاش عکس برای هر نصب و ۵ تلاش عکس برای کل سرویس؛ ۱ تلاش کلیپ برای هر نصب و کل سرویس در روز. سهمیه قبل از درخواست رزرو می‌شود؛ حتی درخواست ناموفق هم یک تلاش را مصرف می‌کند تا تکرار کلیک باعث مصرف چندبارهٔ اعتبار نشود.

مدل متنی فعلی `deepseek-flash` در فهرست رسمی DeepSeek با نرخ پایهٔ ۰٫۱۵ دلار برای هر یک میلیون توکن ورودی و ۰٫۶۰ دلار برای هر یک میلیون توکن خروجی معرفی شده است؛ AvalAI ممکن است تعرفه یا موجودی متفاوتی اعمال کند، پس داشبورد همان حساب معیار نهایی است. یک کلیپ ۴ ثانیه‌ای Veo Fast با نرخ ۰٫۱۵ دلار در ثانیه حدود ۰٫۶۰ دلار و هر تصویر Muse حدود ۰٫۰۱۱۵ دلار است. قبل از روشن‌کردن رسانه، سقف هزینهٔ روزانه و ماهانهٔ حساب را تعیین کن.

## 7) پرداخت آزمایشی و درآمدزایی

مسیرهای `POST /billing/request` و `GET /billing/callback` در backend اضافه شده‌اند. درخواست پرداخت روی سرور ساخته می‌شود، سپس callback با API تأیید زرین‌پال بررسی می‌شود؛ مبلغ دریافتی از مرورگر یا اپ پذیرفته نمی‌شود. دسترسی چت و رسانه پس از پایان دورهٔ آزمایشی از سمت سرور کنترل می‌شود.

- `ZARINPAL_SANDBOX=true` را برای تست نگه دار.
- `ZARINPAL_MERCHANT_ID` و `ARIA_PUBLIC_BASE_URL` لازم‌اند؛ آدرس عمومی باید HTTPS باشد.
- قیمت فعلی از `ARIA_MONTHLY_PRICE_TOMAN` خوانده می‌شود و مقدار نمونه ۹۹٬۰۰۰ تومان است. API زرین‌پال مبلغ را به ریال می‌خواهد، پس backend آن را ×۱۰ می‌کند.
- پس از موفقیت تست sandbox، برای فروش واقعی پذیرندهٔ فعال لازم است و فقط بعد از آن `ZARINPAL_SANDBOX=false` را تنظیم کن.
- هویت گوگل مالک و معافیت مادام‌العمر مالک هنوز پیاده‌سازی نشده؛ هیچ حسابی را صرفاً با واردکردن ایمیل به‌عنوان مالک رایگان نکن.
- پیش از فروش واقعی، حریم خصوصی، شرایط استفاده، بازپرداخت و پشتیبانی منتشر و مسیر پرداخت با تراکنش واقعی کم‌مبلغ آزموده شود.

رسید تصویری یا پیام کاربر اثبات پرداخت نیست. فقط callback تأییدشدهٔ سرور و شناسهٔ مرجع زرین‌پال می‌تواند اشتراک را فعال کند.

## 8) پلن میزبانی

قیمت‌گذاری فعلی Weblines به‌صورت مصرف ساعتی است: Nano با ۵۱۲ مگابایت RAM حدود ۳۱۰٬۳۲۰ تومان در ماه و Micro با ۱ گیگابایت حدود ۶۷۰٬۳۲۰ تومان در ماه در فرض روشن‌بودن ۷۲۰ ساعت؛ Small با ۲ گیگابایت حدود ۱٬۳۴۰٬۶۴۰ تومان برآورد می‌شود. ثبت‌نام جدید طبق صفحهٔ قیمت ۵۰٬۰۰۰ تومان اعتبار اولیه دارد. برای پایلوت Micro را پیشنهاد می‌کنم؛ برای سرویس با چند کاربر هم‌زمان و فایل‌های رسانه، Small امن‌تر است. این اعداد تخمینی‌اند و قیمت/مصرف دیسک در پنل ممکن است فرق کند.

## 9) عیب‌یابی سریع

| علامت | علت محتمل |
|---|---|
| `cloud_ai_configured=false` | کلید AvalAI یا URL مدل روی سرور تنظیم نشده |
| `chat_ready=false` | API Key نامعتبر/ندارد یا سرویس مدل پاسخ نمی‌دهد |
| HTTP 404 برای `/media/image` | دامنه هنوز به backend قدیمی وصل است |
| HTTP 401 در چت | توکن مهمان منقضی شده؛ اپ را ببند و دوباره اتصال بزن |
| HTTP 429 | سهمیهٔ API یا محدودیت آزمایشی تمام شده |
| دیتابیس بعد از Deploy خالی شد | Volume پایدار روی `/data` متصل نیست |

این سرویس پس از تنظیم کلید و استقرار نیاز به تست واقعی از خود گوشی دارد. ساخت APK به‌تنهایی، اتصال سرور یا پرداخت را اثبات نمی‌کند.
