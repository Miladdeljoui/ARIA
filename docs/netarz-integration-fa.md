# اتصال ARIA به نِت‌اَرز / گیسو برای کاربران ایران

وضعیت کد: درگاه NetArz برای چت، دریافت فهرست زندهٔ مدل‌ها، تولید تصویر و تولید ویدئو به سرور ARIA اضافه شده است. این به معنی فعال‌بودن حساب API یا سرور عمومی نیست؛ برای اجرای واقعی، کلید API و استقرار سرور لازم است.

## چرا این سرویس؟

نِت‌اَرز یک درگاه سازگار با OpenAI است. یک کلید برای مدل‌های مستقیم GPT، Gemini و DeepSeek و همچنین مدل‌های Claude، Grok، Mistral، Llama، Qwen و مدل‌های بیشتر از مسیر OpenRouter استفاده می‌شود. مستندات فهرست زندهٔ حدود ۱۶۸ مدل مستقیم و ۵۳۶ مدل OpenRouter را نشان می‌دهد؛ فهرست و قیمت‌ها تغییر می‌کنند، پس خود API منبع نهایی است.

برای VPS و دیتاسنتر داخل ایران، مستند رسمی این نشانی پایه را پیشنهاد می‌کند:
`https://ir.gisoo.pro/api/v1`

نشانی اصلی:
`https://netarz.ir/api/ai/v1`

مراجع:
- شروع سریع و احراز هویت: https://netarz.ir/docs/ai/quickstart
- چت و فهرست مدل‌ها: https://netarz.ir/docs/ai/chat-completions
- مدل‌ها و قیمت زنده: https://netarz.ir/docs/ai/models-and-pricing
- تولید تصویر: https://netarz.ir/docs/ai/images
- تولید ویدئو: https://netarz.ir/docs/ai/video
- سقف‌ها و امنیت کلید: https://netarz.ir/docs/ai/rate-limits-and-security

## هزینه و نکتهٔ «رایگان»

این API رایگان نامحدود نیست و طبق مستند فعلی، مدل رایگان در حال حاضر ارائه نمی‌شود. حداقل شارژ اعلام‌شده ۵۰٬۰۰۰ تومان است و ۹٪ مالیات بر ارزش افزوده پیش از پرداخت نشان داده می‌شود. تا قبل از احراز هویت، سقف مصرف کل حساب ۲ دلار است. قیمت هر مدل متفاوت است؛ تصویر بر اساس توکن/مدل و ویدئو بر اساس ثانیه محاسبه می‌شود.

قبل از شارژ:
1. فقط یک پروژه با نام ARIA بساز.
2. برای کلید، مدل‌های مجاز را محدود کن.
3. سقف هزینهٔ کل و در صورت امکان سقف ماهانه بگذار.
4. اگر IP سرور ثابت شد، IP مجاز کلید را به همان IP محدود کن.
5. تاریخ انقضا برای کلید تست تعیین کن.

کلید را هرگز در APK، GitHub، تلگرام یا چت قرار نده.

## تنظیمات سرور

در Secret / Environment میزبانی، این مقادیر را ثبت کن:

```dotenv
ARIA_PROVIDER=netarz
ARIA_API_BASE_URL=https://ir.gisoo.pro/api/v1/chat/completions
ARIA_API_KEY=کلید_خصوصی_نِت‌اَرز
ARIA_MODEL=deepseek-flash
ARIA_ALLOWED_MODELS=

ARIA_IMAGE_API_URL=https://ir.gisoo.pro/api/v1/images/generations
ARIA_IMAGE_API_KEY=
ARIA_IMAGE_MODEL=gemini-3.1-flash-lite-image
ARIA_IMAGE_QUALITY=low

ARIA_VIDEO_API_URL=https://ir.gisoo.pro/api/v1/videos
ARIA_VIDEO_API_KEY=
ARIA_VIDEO_MODEL=veo-3.1-fast
ARIA_MEDIA_ENABLED=false

ARIA_DB=/data/aria_cloud.db
ARIA_OWNER_NAME=Milad
ARIA_TRIAL_DAYS=30
ARIA_MONTHLY_PRICE_TOMAN=99000
ARIA_PUBLIC_BASE_URL=https://api.your-domain.ir
ZARINPAL_SANDBOX=true
ZARINPAL_MERCHANT_ID=
```

کلید تصویر و ویدئو در صورت خالی‌بودن از `ARIA_API_KEY` استفاده می‌کنند؛ بنابراین با یک کلید واحد کار می‌کند. برای نسخهٔ اول `ARIA_MEDIA_ENABLED=false` بماند. پس از تست یک چت و تعیین سقف خرج در پنل نِت‌اَرز، می‌توان آن را `true` کرد.

فهرست مدل چت از `GET /models?type=chat` گرفته می‌شود و در ARIA از مسیر `GET /models` نمایش داده می‌شود. برای محدودکردن گزینه‌های قابل انتخاب، شناسه‌ها را در `ARIA_ALLOWED_MODELS` با کاما جدا کن. نمونهٔ شناسهٔ Claude:
`openrouter/anthropic/claude-sonnet-4.5`
شناسهٔ درست باید از فهرست زنده برداشته شود؛ نام‌های قدیمی ممکن است 404 شوند.

## ساخت تصویر و کلیپ

- تصویر: `POST /images/generations`. کد ARIA از مدل Lite تصویری Gemini با وضوح 1K آغاز می‌کند تا مصرف اولیه کنترل شود. مدل‌های GPT Image و Nano Banana دیگر نیز از همین endpoint قابل انتخاب‌اند.
- کلیپ: `POST /videos`، سپس بررسی وضعیت `GET /videos/{id}` و دریافت فایل `GET /videos/{id}/content`. سرویس رندر ناهمگام است و ممکن است چند دقیقه طول بکشد.
- تولید تصویر و ویدئو هزینهٔ جداگانه دارند. برای ویدئو، قیمت هر ثانیه و ضریب وضوح مدل را پیش از هر ارتقا بررسی کن. تا زمانی که صفحهٔ برنامه هزینه را قبل از درخواست نمایش نمی‌دهد، ویدئو را فقط برای تست مالک و با سهمیهٔ خیلی محدود روشن کن.

## میزبانی

برای بازار ایران، Weblines Cloud یکی از گزینه‌های موجود در اسناد پروژه است. سرور کوچک بدون GPU کافی است، چون محاسبهٔ مدل در سرویس API انجام می‌شود و VPS فقط درگاه ARIA، پایگاه داده و ارتباط Android را مدیریت می‌کند.

قیمت منتشرشدهٔ Weblines را در زمان خرید دوباره بررسی کن:
https://www.weblines.ir/pricing

در صفحهٔ فعلی، Nano با ۲۵۰m CPU، نیم گیگ RAM و ۱GB دیسک ۴۳۱ تومان در ساعت است؛ Micro با ۵۰۰m CPU، ۱GB RAM و ۵GB دیسک ۹۳۱ تومان در ساعت. برای استفادهٔ واقعی، فایل SQLite را روی Volume پایدار `/data` بگذار؛ دیسک موقت کانتینر برای نگهداری اشتراک‌ها و پرداخت‌ها کافی نیست. دامنهٔ HTTPS لازم است.

راهنمای Docker موجود:
- `cloud/Dockerfile`
- `cloud/docker-compose.remote.yml`
- `cloud/Caddyfile`

## وضعیت کد ورود و چت

نسخهٔ فعلی Android برای هر نصب یک شناسهٔ تصادفی تولید می‌کند و از endpoint `/guest` توکن می‌گیرد؛ کد ۶ رقمی جفت‌سازی در مسیر عادی اتصال استفاده نمی‌شود. اپ به آدرس HTTPS سرور ARIA وصل می‌شود، نه مستقیماً به کلید NetArz. اگر نشانی سرور در تنظیمات خالی باشد یا backend جدید deploy نشده باشد، چت کار نخواهد کرد.

پس از Deploy:
1. در گوشی آدرس HTTPS سرور را در تنظیمات ARIA وارد کن.
2. «اتصال مجدد» را بزن.
3. `/status` باید `chat_ready: true` نشان دهد.
4. یک پیام آزمایشی بفرست و سپس در فهرست مدل‌ها یک مدل دیگر انتخاب کن.
5. تصویر و ویدئو را تنها پس از فعال‌کردن کلید، سقف هزینه و `ARIA_MEDIA_ENABLED=true` تست کن.

## درآمدزایی؛ گیت‌های اجباری

کد اشتراک ۳۰ روزه، قیمت نمونهٔ ۹۹٬۰۰۰ تومان و callback زرین‌پال دارد، اما پرداخت تا تنظیم Merchant ID واقعی و HTTPS، خاموش/آزمایشی است. فروش عمومی فقط بعد از این موارد:
- اتصال چت و ثبت مصرف به‌صورت موفق روی سرور پایدار.
- محدودیت هزینه بر اساس حساب و مدل، نه فقط تعداد درخواست.
- سهمیهٔ جدا برای چت، تصویر و کلیپ و قطع خودکار هنگام رسیدن به سقف ریالی.
- تست callback و تأیید سمت سرور زرین‌پال در حالت واقعی با مبلغ کم.
- سیاست حریم خصوصی، شرایط استفاده، لغو/بازپرداخت و پشتیبانی.
- تست APK روی گوشی واقعی و شبکهٔ ایران.

مدل درآمد پیشنهادی اولیه: پلن رایگان با سهمیهٔ کم چت، اشتراک ماهانه برای مدل‌های اقتصادی، و کیف پول/اعتبار جدا برای مدل‌های گران و رسانه. «اشتراک نامحدود» برای تصویر و ویدئو نفروش؛ مصرف هر کلیپ می‌تواند چند برابر هزینهٔ چند روز چت باشد.

**تا زمانی که کلید، سرور، درگاه و تست گوشی واقعی انجام نشده، ARIA را نسخهٔ آزمایشی معرفی کن و پرداخت کاربران را دریافت نکن.**
