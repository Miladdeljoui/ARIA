# ربات تلگرام ARIA: پرداخت و اشتراک کلیپ‌ساز

این پوشه ماژول مستقل پرداخت و سهمیه کلیپ‌ساز ربات تلگرام را نگه می‌دارد. این ماژول با پلن‌های اشتراک اپلیکیشن Android یکی نیست.

## پلن‌های تأییدشده

| پلن | قیمت | مدت | سهمیه |
|---|---:|---:|---:|
| هفتگی | ۶۰۰٬۰۰۰ تومان | ۷ روز | ۲۸ کلیپ، حداکثر ۴ کلیپ در روز |
| ماهانه | ۲٬۴۰۰٬۰۰۰ تومان | ۳۰ روز | ۱۴۰ کلیپ |

## جریان پرداخت

1. کاربر از منوی «خرید اشتراک» پلن را انتخاب می‌کند.
2. اطلاعات حساب مقصد از متغیرهای محیطی خوانده می‌شود.
3. کاربر تصویر رسید را ارسال می‌کند.
4. ربات درخواست و تصویر را برای مدیر می‌فرستد.
5. مدیر مبلغ و تراکنش را در بانک مستقل بررسی می‌کند و سپس تأیید یا رد می‌کند.
6. تأیید پرداخت فقط یک‌بار مجاز است و اشتراک در SQLite ثبت می‌شود.
7. اگر اشتراک دیگری فعال باشد، خرید تازه بعد از پایان آخرین دوره موجود صف می‌شود.
8. رزرو کلیپ سهمیه را کم می‌کند و اگر ساخت کلیپ شکست بخورد، سهمیه همان روز و همان اشتراک برگردانده می‌شود.

**هشدار:** تصویر رسید به‌تنهایی اثبات واریز نیست. دکمه تأیید فقط پس از تطبیق مبلغ، تاریخ و شناسه تراکنش با گردش واقعی حساب استفاده شود. ربات عمداً پرداخت را فقط با OCR یا تصویر خودکار تأیید نمی‌کند.

## متغیرهای محیطی

این نام‌ها باید در فایل .env سرور موجود باشند. مقدار واقعی آن‌ها هرگز نباید در Git ثبت شود:

- ARIA_ADMIN_ID
- ARIA_BANK_NAME
- ARIA_CARD_NUMBER
- ARIA_ACCOUNT_HOLDER

توکن ربات و کلیدهای سرویس‌های دیگر نیز فقط در .env سرور باقی می‌مانند.

## فایل‌ها

- billing.py: تراکنش‌های SQLite، پرداخت، صف اشتراک و سهمیه کلیپ.
- billing_handlers.py: رابط تلگرام برای خرید، دریافت رسید و تصمیم مدیر.
- clip_service.py: ساخت کلیپ Replicate با رزرو و بازگشت سهمیه.
- install_billing.py: وصله‌زن تکرارپذیر برای افزودن import و ثبت handler به bot.py و کپی ماژول‌ها در Docker image.
- tests/test_billing.py: آزمون سهمیه، پرداخت تکراری، صف اشتراک و بازگشت سهمیه.

## نصب روی VPS فعلی

ابتدا از مسیر /opt/aria-public فایل‌های این شاخه را دانلود کنید:

```bash
cd /opt/aria-public
curl -fsSL https://raw.githubusercontent.com/Miladdeljoui/ARIA/telegram-bot-billing/telegram-bot/billing.py -o billing.py
curl -fsSL https://raw.githubusercontent.com/Miladdeljoui/ARIA/telegram-bot-billing/telegram-bot/billing_handlers.py -o billing_handlers.py
curl -fsSL https://raw.githubusercontent.com/Miladdeljoui/ARIA/telegram-bot-billing/telegram-bot/clip_service.py -o clip_service.py
curl -fsSL https://raw.githubusercontent.com/Miladdeljoui/ARIA/telegram-bot-billing/telegram-bot/install_billing.py -o install_billing.py
python3 install_billing.py
```

نصب‌کننده از bot.py و Dockerfile نسخه پشتیبان می‌گیرد، سپس ماژول‌ها را به Docker image اضافه و handlerهای پرداخت را پیش از callback عمومی ثبت می‌کند. این اسکریپت کانتینر را Restart نمی‌کند.

پس از وصله‌زنی، ابتدا syntax و build را بررسی کنید. تا پیش از موفقیت تست‌ها، کانتینر فعلی را جایگزین نکنید.

## ساخت کلیپ

دکمه «ساخت کلیپ» در منوی ربات، متن درخواست را می‌گیرد و از مدل Replicate برای text-to-video استفاده می‌کند. پیش از ارسال درخواست، سهمیه در SQLite رزرو می‌شود. در صورت شکست ساخت یا ارسال ویدئو، سهمیه به همان تاریخ تهران بازگردانده می‌شود. برای حفظ منابع VPS، هم‌زمان فقط یک ساخت کلیپ اجرا می‌شود. سقف دانلود ویدئو ۴۵ مگابایت است. در این نسخه ورودی متن پشتیبانی می‌شود؛ ورودی تصویر به مرحله بعد موکول شده است.

## آزمون‌ها

```bash
cd telegram-bot
python -m unittest discover -s tests -v
```

این تست‌ها پایگاه داده موقت می‌سازند و به .env یا سرویس بانکی دسترسی ندارند.
